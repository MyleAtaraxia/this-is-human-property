# Agent rules
The binding rules for this repo are in AGENTS.md at the repo root. Read it first and follow it exactly.

Summary: no vibe coding. Agents do research, explanation, code review, and small single-function edits (~30 lines max) only when explicitly asked. No new files, multi-file edits, refactors, dependency or build changes, edits to third_party/, or git commits/pushes. If a request is larger, refuse the code and give guidance instead.
